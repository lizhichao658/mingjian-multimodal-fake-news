# 第三方来源与开源合规清单

## 必填项

- [ ] 第三方预训练模型名称、版本、许可证、下载来源；
- [ ] 数据集名称、版本、许可证、引用论文；
- [ ] 使用的库及其许可证；
- [ ] 明确哪些代码为自研，哪些为标准组件调用；
- [ ] 仓库中不包含 ComP 源码或派生代码；
- [ ] 不包含未经许可的数据与个人信息；
- [ ] 技术文档与 README 中声明参考论文。

## MIAN / IMOL 参考边界

- 可以作为研究思想参考；
- 不复制代码（MIAN 论文没有提供本机代码）；
- 不使用其模块名作为我们的核心模块名；
- 不声称复现其全部实验；
- 在技术文档中明确“参考思想”与“自研实现”的区别。

## ComP 边界

- 只作为同领域背景认知；
- 不复制代码、目录结构、命名、注释；
- 不放入参赛仓库；
- 不将“补齐 ComP 缺失模块”作为项目路线。
