# 明鉴数据卡 v0.1（待补充）

## 数据原则

- 只使用许可明确、可追溯的数据；
- 原始数据不提交公开仓库；
- 明确标注数据来源、时间范围、语言、领域和标签来源；
- 个人信息、隐私内容和敏感数据必须脱敏或删除；
- 演示样例与训练数据严格区分。

## 本仓库的数据格式

每行一个 JSON 对象，字段见 `data/README.md`：

- `sample_id`：唯一标识；
- `text`：新闻文本；
- `image_path`：图像路径；
- `label`：0=假，1=真；
- `split`：train/val/test；
- `source`：数据来源；
- `metadata`：附加信息。

## 标注与偏差风险

- 不同数据集的“假新闻”定义可能不同；
- 政治、娱乐、社会等领域分布不均衡；
- 真假标签来源可能带有平台或机构偏差；
- 图像可能被裁剪、压缩、加 watermark，影响特征；
- 无法保证测试集与真实部署环境同分布。
