# 明鉴数据卡 v0.1（合规核验中）

## 数据原则

- 只使用许可明确、来源可追溯的数据；
- 原始数据不提交公开仓库，不随演示包再分发；
- 明确标注数据来源、时间范围、语言、领域和标签来源；
- 个人信息、隐私内容和敏感数据必须脱敏或删除；
- 演示样例与训练数据严格区分；
- 数据集名称不得混用，指标必须注明数据集和实验协议。

## 计划使用的数据集

| 数据集 | 语言 | 官方建模输入 | 项目角色 | 状态 |
|---|---|---|---|---|
| Weibo17 / EANN Weibo | 中文 | 文本 + 图像 | 主多模态训练与测试 | 待核验 `dataformat.txt`、许可、引用要求 |
| Weibo21 / MDFEND | 中文 | 文本（公开划分字段为 `content`、`label`、`category`） | 文本跨域、缺图像降级评测 | 待通过官方表单申请并保存许可记录 |
| Fakeddit | 英文 | 文本 + 图像 | 备选跨语言实验 | 待核验许可与子集方案 |
| GossipCop / PolitiFact | 英文 | 文本 | 跨域评测 | 待核验；不作为第一版主训练集 |

> 说明：Weibo21 在 MDFEND 官方实现和已知公开划分中是文本建模基准；不能用“文本 + 单图”标签描述该基准，除非另行获得并核验带图像的原始版本及字段说明。

## 本仓库的数据格式

每行一个 JSON 对象，字段见 `data/README.md`：

- `sample_id`：唯一标识；
- `text`：新闻文本；
- `image_path`：图像路径；
- `label`：0=假，1=真；
- `split`：train/val/test；
- `source`：数据来源；
- `metadata`：附加信息。

## 标注与偏差风险

- 不同数据集的“假新闻”定义可能不同；
- 政治、娱乐、社会等领域分布不均衡；
- 真假标签来源可能带有平台或机构偏差；
- 图像可能被裁剪、压缩、加 watermark，影响特征；
- 平台帖子可能包含个人信息，使用前必须检查并脱敏；
- 无法保证测试集与真实部署环境同分布。

## 当前状态

- 仅有一个合成演示样例生成脚本；
- 尚未下载或打包任何真实数据集；
- Weibo17 和 Weibo21 的许可、获取方式与字段映射尚未完成最终核验；
- 正式训练前必须完成数据许可核对，并保留申请与许可证据。
