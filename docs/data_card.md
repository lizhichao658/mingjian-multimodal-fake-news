# 明鉴数据卡 v0.2（Weibo17 格式已核验，许可待闭环）

## 数据决策

- 第一版正式实验**只使用 Weibo17 / EANN Weibo**；
- 不使用 Weibo21、Fakeddit、GossipCop 或 PolitiFact 作为正式训练、验证或测试数据；
- 缺模态评测从 Weibo17 测试集内部构造“移除图像”子集；
- 跨域或泛化评测仅在 Weibo17 元数据支持时，按事件、领域或时间留出内部子集。

## 数据原则

- 只使用许可明确、来源可追溯的数据；
- 原始数据不提交公开仓库，不随演示包再分发；
- 明确标注数据来源、时间范围、语言、领域和标签来源；
- 个人信息、隐私内容和敏感数据必须脱敏或删除；
- 演示样例与训练数据严格区分；
- 报告中的指标必须注明 Weibo17 版本、划分协议和是否缺图。

## 本仓库的数据格式

每行一个 JSON 对象，字段见 `data/README.md`：

- `sample_id`：唯一标识；
- `text`：新闻文本；
- `image_path`：图像路径；
- `label`：0=真实/非谣言，1=虚假/谣言（EANN Weibo17 官方协议）；
- `split`：train/val/test；
- `source`：数据来源，固定指向 Weibo17 版本；
- `metadata`：附加信息。

## 标注与偏差风险

- Weibo17 的标注规范与人工判定标准仍需以原论文/数据说明为准；当前已确认标签方向与预处理协议，但未确认许可；
- 政治、娱乐、社会等领域分布可能不均衡；
- 真假标签来源可能带有平台或机构偏差；
- 图像可能被裁剪、压缩、加 watermark，影响特征；
- 平台帖子可能包含个人信息，使用前必须检查并脱敏；
- 无法保证 Weibo17 测试集与真实部署环境同分布。

## 核验记录（2026-10-03）

- 官方入口为 `yaqingwang/EANN-KDD18` 发布的 `weibo.zip`，精确大小 `1,359,648,341` 字节；
- 通过 ZIP 中央目录与 HTTP Range 在内存中核验，未把原始文本、样本 ID 列表或图片写入仓库；
- 文本池共 `9,527` 条，官方三个 pickle 共 `7,723` 个唯一 ID，官方 ID 全部能在文本池中定位；
- 官方划分为 train `5,415`、validate `843`、test `1,465`，事件集合互不重叠；
- 官方标签契约与 EANN 预处理代码一致：`0 = real/non-rumor`，`1 = fake/rumor`；
- 官方标签数为 real `3,615`、fake `4,108`；三个划分均同时包含两类；
- 官方 `7,723` 条记录全部能匹配到对应类别的归档图片，且没有跨官方划分或跨标签的图片名复用；
- 官方 `7,723` 条记录没有空正文、没有缺失非空图片 URL；
- 官方整体存在 `108` 个重复文本组、`156` 条超出首条的重复记录、`264` 个重复对，最大组 `10` 条；没有跨官方划分或跨标签重复；
- 划分内部重复为：train `78` 组 / `115` 条超出，validate `11` 组 / `17` 条超出，test `19` 组 / `24` 条超出；正式报告必须披露；
- 四个文本文件名不是官方划分边界，必须使用三个 pickle 映射；
- 图片复用审计按文件名主干统计，不等价于图像内容哈希去重；
- MIAN 论文中的 `9,411` 条是完整文本池去除 `116` 条空正文后的口径，其划分协议与 EANN 官方 `7,723` 条不同，禁止混用。
