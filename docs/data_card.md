# 明鉴数据卡 v0.3（Weibo17 本地完整归档已核验，许可待闭环）

## 数据决策

- 第一版正式实验**只使用 Weibo17 / EANN Weibo**；
- 不使用 Weibo21、Fakeddit、GossipCop 或 PolitiFact 作为正式训练、验证或测试数据；
- 缺模态评测从 Weibo17 测试集内部构造“移除图像”子集；
- 跨域或泛化评测仅在 Weibo17 元数据支持时，按事件、领域或时间留出内部子集。

## 数据原则

- 只使用许可明确、来源可追溯的数据；
- 原始数据不提交公开仓库，不随演示包再分发；
- 明确标注数据来源、时间范围、语言、领域和标签来源；
- 个人信息、隐私内容和敏感数据必须脱敏或删除；
- 演示样例与训练数据严格区分；
- 报告中的指标必须注明 Weibo17 版本、划分协议和是否缺图。

## 本仓库的数据格式

每行一个 JSON 对象，字段见 `data/README.md`：

- `sample_id`：唯一标识；
- `text`：新闻文本；
- `image_path`：图像路径；
- `label`：0=真实/非谣言，1=虚假/谣言（EANN Weibo17 官方协议）；
- `split`：train/val/test；
- `source`：数据来源，固定指向 Weibo17 版本；
- `metadata`：附加信息。

## 标注与偏差风险

- Weibo17 的标注规范与人工判定标准仍需以原论文/数据说明为准；当前已确认标签方向与预处理协议，但未确认许可；
- 政治、娱乐、社会等领域分布可能不均衡；
- 真假标签来源可能带有平台或机构偏差；
- 图像可能被裁剪、压缩、加 watermark，影响特征；
- 平台帖子可能包含个人信息，使用前必须检查并脱敏；
- 无法保证 Weibo17 测试集与真实部署环境同分布。
