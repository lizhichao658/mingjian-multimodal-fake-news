# 明鉴模型卡 v0.1（未训练）

## 模型名称

明鉴图文虚假新闻辅助研判 baseline。

## 当前版本

- 版本：0.1.0
- 状态：仅完成特征融合 baseline 与冒烟测试，尚未在真实数据上训练。
- 输入：新闻文本 + 单张新闻图像。
- 输出：fake 类 logit；经 sigmoid 后解释为 P(fake)，P(real) = 1 - P(fake)。后续扩展风险等级与证据。

## 预期用途

- 内容审核初筛；
- 事实核查辅助；
- 教学与研究复现。

## 明确不适用的用途

- 不可作为事实认定、法律判断或行政处置的唯一依据；
- 不可用于对个人、组织进行无人工复核的自动定性；
- 不可直接用于高风险领域（医疗、选举、司法）的自动决策。

## 当前结构

1. 文本编码器：计划使用中文预训练语言模型，当前仅提供可选包装。
2. 图像编码器：计划使用 ViT/CLIP，当前仅提供可选包装。
3. Baseline：将池化文本特征与图像特征投影、拼接、MLP 分类。
4. 后续：局部上下文精炼、全局语义校准、一致性/矛盾性双通道、可靠性路由、温度校准与证据解释。

## 训练数据

第一版只使用 Weibo17（EANN Weibo）。字段与划分格式已核验；按公开研究数据路线本地训练，不重新分发原始数据、不声称已获授权。

## 评测指标

- Accuracy、Precision、Recall、F1、AUC；
- ECE（置信度校准误差）；
- 缺模态场景性能；
- 跨域场景性能；
- 推理延迟。

## 已知限制

- 尚未接入真实数据集和编码器；
- 尚无真实实验指标；
- 尚未验证中文/英文跨域表现；
- 尚未实现图像篡改细粒度定位；
- 尚不能判断绝对真假。

## 伦理与合规

- 所有高风险结论必须人工复核；
- 明确展示模型不确定性与已知限制；
- 不收集或公开个人信息；
- 第三方模型、数据、论文必须声明来源。
