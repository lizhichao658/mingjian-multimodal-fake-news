# 明鉴架构说明 v0.1

## 1. 第一版范围

输入新闻文本 + 单张图像，输出 P(real)、风险等级、一致/矛盾分数与证据。

## 2. 代码分层

```text
data/schema.py      数据契约
data/dataset.py     JSONL 读写与数据集
models/encoders.py  可选 HuggingFace 编码器包装
models/baseline.py  特征融合 baseline 与测试模型
training/engine.py  通用训练/评估循环
evaluation/metrics.py 指标与校准
```

## 3. 计划中的模型模块

1. **语义切片编码器**：文本 token + 图像 patch。
2. **局部上下文精炼器**：单模态自注意力。
3. **全局语义校准器**：全局向量校准局部表示。
4. **双通道跨模态交互器**：
   - 一致通道：跨模态相似信息；
   - 矛盾通道：差异权重 top-k 聚合；
   - 门控融合。
5. **可靠性路由器**：模态 mask、质量分数、降级推理。
6. **证据聚合与校准头**：分类 logits、一致/矛盾分数、温度缩放。
7. **解释器**：文本 token、图像 patch、跨模态证据对。

## 4. 训练阶段

- 阶段 A：冻结编码器，训练上层 baseline；
- 阶段 B：解冻顶部或使用 LoRA；
- 阶段 C：模态 dropout、类不平衡、校准与鲁棒性评估。
