# 明鉴项目章程 v0.2

## 1. 目标

构建一个可复现、可解释、可演示的多模态虚假新闻辅助研判系统。第一版处理新闻文本 + 单张图像，输出真假概率、风险等级、文本/图像证据和人工复核提示。

## 2. 用户

- 内容审核员：筛选高风险内容，进入人工复核。
- 事实核查人员：定位可疑文本片段和图像区域。
- 普通用户：了解可疑内容的风险和依据。
- 开发者/研究者：复现训练、评测和解释流程。

## 3. MVP 范围

已在当前 lite MVP 中完成：

- 文本 + 单图输入，支持缺图降级；
- Weibo17 本地数据适配器、字符分词器和 PyTorch 数据管线；
- 自包含 TextCNN + ImageCNN + 门控融合 baseline；
- 真实数据训练、验证、测试和阈值调优；
- 文本梯度证据、图像 Grad-CAM、模态贡献输出；
- 无 API Key 本地工作台和历史记录；
- 模型卡、数据卡、复现说明和测试。

后续增强（不阻塞第一版提交）：

- 显式一致性与矛盾性双通道；
- 可靠性路由和缺模态重训练；
- 温度缩放等概率校准；
- 批量检测、导出和完整审核动作闭环；
- 更多消融、跨域和鲁棒性实验；
- 可选的预训练编码器替换实验。

暂不纳入：

- 视频、音频、OCR 全链路；
- 深度伪造检测；
- 外部知识库全量接入；
- 大规模爬虫与实时舆情监控。

## 4. 成功标准

- 从数据到训练、推理、解释和界面的最小闭环可运行；
- 关键指标与训练日志可追溯，不编造结果；
- 至少完成三类结构化测试：数据/模型单元测试、端到端推理、缺图降级；
- 提供无 API Key 的演示路径；
- Git 提交细粒度，至少保留三条 Prompt 链；
- 对过拟合、校准不足和单数据集域限制进行明确披露。

## 5. 约束

- 单人开发，优先小闭环和可复现。
- 不得复制 ComP 或其他开源项目源码。
- 第三方模型、数据与论文必须声明。
- 原始数据、图片和权重不进入 Git。
- 所有高风险结论必须有人工复核提示。
