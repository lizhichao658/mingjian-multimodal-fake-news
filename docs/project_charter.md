# 明鉴项目章程 v0.1

## 1. 目标

构建一个可复现、可解释、可演示的多模态虚假新闻辅助研判系统。第一版处理新闻文本 + 单张图像，输出真假概率、风险等级与图文证据。

## 2. 用户

- 内容审核员：批量筛选高风险内容，进入人工复核。
- 事实核查人员：定位图文矛盾证据，辅助核查。
- 普通用户：了解可疑内容的风险和依据。
- 开发者/研究者：复现训练与评测流程。

## 3. MVP 范围

必须完成：

- 文本 + 单图输入；
- 冻结编码器 + 上层融合 baseline；
- 自研一致性/矛盾性双通道模型；
- 缺模态降级与不确定性标记；
- 校准概率与风险分级；
- 文本/图像/跨模态证据输出；
- Web 单条检测、历史记录、演示模式；
- 模型卡、数据卡、10 分钟复现说明。

暂不纳入：

- 视频、音频、OCR 全链路；
- 深度伪造检测；
- 外部知识库全量接入；
- 大规模爬虫与实时舆情监控。

## 4. 成功标准

- 有一个从数据到训练到推理到界面的完整闭环；
- 关键实验可复现，指标与日志可追溯；
- 至少完成三组消融：去矛盾通道、去可靠性路由、去校准；
- 至少完成三种鲁棒性测试：缺文本、缺图像、低质量图像；
- 提供无 API Key 的演示路径；
- Git 提交细粒度，Prompt 链可审计。

## 5. 约束

- 单人开发，优先小闭环。
- 不得复制 ComP 或其他开源项目源码。
- 第三方模型、数据与论文必须声明。
- 高硬件需求的功能后置，先保证 CPU 也能跑通结构测试。
- 所有高风险结论必须有人工复核提示。
